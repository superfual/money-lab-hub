# Money Lab — Illustrated world (v11)

Built-in image generation was used for two original game assets, then copied unchanged into the Site repository. Both retain alpha transparency. No labels or financial values are baked into the images; VI/EN text remains native HTML.

Project assets:

- `/workspace/scratch/84513b05f011/money-lab/dist/assets/money-town-v1.png`: financial-town illustration for the introduction and board center.
- `/workspace/scratch/84513b05f011/money-lab/dist/assets/financial-pieces-v1.png`: one 3 × 2 sprite atlas for Start, Opportunity, Unexpected, Knowledge, Market and Income. Displayed using CSS background positioning, with no file cropping or visual edits.

Palette: forest emerald, ivory, pale sage, muted gold and restrained terracotta. Medium: collectible tabletop clay/ceramic miniatures with soft shadows. These are decorative fictional scenes, not live financial charts. Labels, input controls, token balances and the board rules remain separate and unchanged.

## Town generation prompt

Use case: stylized-concept. Asset type: finished 3D game illustration for the center of Money Lab, a financial education board game. Create ONE square 1024x1024 premium isometric miniature financial town on a floating rounded square cream platform, all objects contained with generous 10 percent transparent margins. A friendly emerald-roof home, tiny classical savings bank, small cafe with striped sage awning, compact office tower, golden coin stacks, miniature gold pedestrian pawn and a winding path connecting them, restrained miniature greenery. High-end tactile clay and smooth ceramic 3D render, inviting tabletop collectible aesthetic for adults, soft studio shadows, warm ivory, forest emerald, pale sage and muted metallic gold, restrained terracotta accent. Clear large forms readable at 250px, carefully balanced composition and craftsmanship, slightly elevated three-quarter isometric camera. Transparent background, no surrounding environment, no text, no logos, no watermarks, no cryptocurrency brand marks, no charts or numbers. This is decorative world art, not a playable board or UI mockup.

## Sprite-atlas generation prompt

Use case: stylized-concept. Asset type: a single transparent game-art SPRITE ATLAS, landscape 1536x1024 with EXACTLY 3 equal columns and 2 equal rows, each of six cells 512x512. Six separate isolated high-end isometric clay/ceramic miniature objects, precisely centered in their own cell with generous empty margins, uniform camera, scale and light. TOP LEFT: emerald start flag on a short cream pedestal with a tiny gold pathway. TOP MIDDLE: elegant miniature savings bank with emerald roof and a stack of gold coins representing investment opportunities. TOP RIGHT: tiny terracotta gift box with a cream smartphone and a gold luggage bag representing unexpected spending choices. BOTTOM LEFT: a beautiful open cream book with emerald cover and small gold graduation cap representing financial knowledge. BOTTOM MIDDLE: three simple dimensional bars and a curved gold market trend arrow representing market changes, no numeric data. BOTTOM RIGHT: emerald briefcase with a few cream banknotes and gold coins representing salary. Premium polished collectible toy aesthetic for adult educational game, soft studio ambient occlusion, forest green, warm ivory, pale sage, muted metallic gold, subtle terracotta. All six distinct silhouettes fully visible and separate; do not let anything cross into adjacent cells. No frames, borders, grid lines, text, letters, numbers, logos, watermarks, background scenes or extra objects. Genuinely transparent background. This entire atlas is ONE image asset and will be displayed with CSS background positioning.

## Scope

This release changes presentation only. It does not add wallet connection, token issuance, transfers or real-money rewards. The TapeOut circuit continues to be read without wallet signing.
