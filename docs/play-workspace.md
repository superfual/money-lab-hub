# Current responsive play workspace

PC uses a board-and-decision layout with two compact cash-flow/portfolio cards immediately beneath the board. Short laptop viewports place money-management controls beside the board; the chart is expandable. Phones stack readable content; no guarantee is made that an entire game workspace fits a single phone viewport. The decision card repeats the current month indicator near its heading.

The shared emerald-and-silver theme covers Solo, multiplayer, Testnet/Mainnet and investment-world pages. Open/locked campaign progress chips explicitly use dark ink on silver; their checked gradient contrast endpoints exceed 4.5:1. This is a targeted contrast check, not a complete accessibility audit. Some visual screenshots in this repository precede the new theme.

These presentation changes do not alter the accounting or blockchain contracts. For the separate current timer rule, see [decision timing](turn-timer.md).
